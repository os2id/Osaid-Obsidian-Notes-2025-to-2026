### ✅ Comment / Uncomment whole line(s)
- **Windows / Linux:**  
    **`Ctrl + /`**

## 🔹 Code Editing Shortcuts

### ✂️ Duplicate line

- **VS Code / PyCharm:**  
    **`Shift + Alt + ↓`** (up arrow to duplicate above)
    

### 🗑️ Delete entire line

- **`Ctrl + Shift + K`** (VS Code)

### 🔼 Move line up / down

- **`Alt + ↑`**
    
- **`Alt + ↓`**


## 🔹 Selection & Navigation

### 🔲 Select entire line

- **`Ctrl + L`**
    

### 🔍 Find

- **`Ctrl + F`**
    

### 🔁 Find & Replace

- **`Ctrl + H`**### 📂 Go to file quickly

- **VS Code:** `Ctrl + P`



### 📂 Go to file quickly

- **VS Code:** `Ctrl + P`


## 🔹 Formatting & Indentation (VERY IMPORTANT IN PYTHON)

### ➡️ Indent line(s)

- **`Tab`**
    

### ⬅️ Un-indent line(s)

- **`Shift + Tab`**


### 🎯 Auto-format code

- **VS Code:**  
    **`Shift + Alt + F`**

## 🔹 Running & Debugging

### ▶️ Run Python file

- **VS Code:**  
    **`Ctrl + F5`**



### 🐞 Debug

- **VS Code:** `F5`



## 🔹 Python-Specific Productivity

### 🧠 Show function parameters / help

- **`Ctrl + Shift + Space`**
    

### ✨ Auto-complete

- **`Ctrl + Space`**

### ✍️ Multiple cursors
