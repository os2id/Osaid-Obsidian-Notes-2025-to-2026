==COMMAND PROMPT TERMINAL COMMANDS (CMD):==
0- [git --version] To check if you really downloaded Git in your laptop, if it showed you the version on the CMD then it is downloaded
1- [cd <,directory name>] To move to a specific Directory
2- [cd ..] To leave the directory we are in and go back one level
3- [mkdir <,the file you want to name>] To create a directory in the path we are in 
4- [pwd] To see where are you currently, in which directory you are in
5- [dir] To show us all the directories we have in our path we are in
6- [notepad <,TXT file name>] or [type nul > <,filename.txt>] To create a txt file
7- [explorer .] To open the current folder/directory we are in
