**Week 1: Building the Foundation**

**Day 1 (Full Body Workout) - REST 1 MINUTE BETWEEN EACH SET:**
0- Warm up for 5 to 10 minutes

1- Push-ups for 3 sets  
10 repetitions each set

2- Squats for 3 sets  
15 repetitions each set

3- Plank for 3 sets  
20 seconds each set

4- Jumping Jacks for 3 sets  
30 seconds each set

5- Walk for 30 minutes or 45 minutes maximum (NO MORE THAN THAT)





**Day 2 (Pull Workout) - REST 1 MINUTE BETWEEN EACH SET:**
0- Warm up for 5 to 10 minutes

1- High-bar Australian row for 3 sets 
10 repetitions each set

2- Negative Pull ups (Try to hold when you are up) for 3 sets
5 repetitions each set

3-  Inverted Row (Beginner Level) for 3 sets
12 repetitions (Decrease 2 repetitions every set)

4- Dead hang for 3 sets
10 seconds (Decrease 2 seconds every set)

5- Walk for 30 minutes or 45 minutes maximum (NO MORE THAN THAT)
